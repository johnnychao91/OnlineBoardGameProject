# Role portraits and encrypted-call card artwork

Generated with the built-in image generation tool. These are original raster illustrations created for the optional art style. Portraits and tool/resource props retain their transparent backgrounds; the card face retains opaque parchment. No commercial character, logo or copied game artwork is used.

The card image deliberately contains no numbers: the application renders the actual card values as accessible text. Hidden cards must continue using a shared card back. A role portrait may only be selected after that role is visible to the current viewer.
