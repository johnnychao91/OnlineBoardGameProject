# 銀月列車

夜行列車穿越荒野，狼人混入乘客。每晚車廂熄燈後有人遇害，倖存者白天在餐車討論放逐對象。角色名稱保留，說明與原創美術採蒸汽列車、煤油燈、紅絨座椅及滿月主題。

本頁是本平台公開房規。同名角色在其他版本可能有不同裁定；等待室先顯示本局規則，開局固定保存。「變體」不表示官方認證或已通過勝率平衡測試。

## 房間與模式

6～12 位參與玩家，觀戰不占席位。開房不指定人數；房主在等待室選配置，依實際入座人數驗證開局，不會偷偷增減角色。修改設定後全員重新準備。

- **線上模式**：使用邀請、重連、觀戰、復盤、戰報、統計及房主管理。外部文字或語音討論自行安排，發言倒數不控制通話軟體麥克風。
- **現場輔助模式**：每人用自己的手機、平板或電腦，由伺服器發角色、計時、處理技能與勝敗，取代人工裁判。

## 夜間與保密

每人只收到自己的角色與授權情報，全員確認後開始第一晚。狼隊私人相認，其餘人不能看到他人角色。收起私人資訊或離開分頁時，名冊私人陣營顏色同步隱藏；回來需手動展開。

夜序固定 **守衛 → 狼人 → 預言家 → 女巫**，只保留開局有配置的職業；特殊狼人也產生狼人時段。被動技能不增加夜間時段。有配置但後來死亡的職業仍保留完整時段。神職完成、放棄、死亡或藥劑耗盡都不提前結束，避免從時間推測存活。公開畫面只顯示職業及段數，不公布技能送出狀態。

所有人每段都有操作面板，非當段技能者、死亡者與完成技能者可巡查票券。只有點到亮起票券才增加巡查次數並換下一張。掩護操作只在本機，不進入歷史、統計、投票或準備，不設全員完成門檻。

首夜無刀仍保留狼隊相認時段，不能選襲擊目標或啟動一致選人的提前期限；其他職業正常行動。

### 守衛

守護一位存活乘客或放棄，可以自守，不能連續兩晚守同一人；上一晚放棄後可再守先前目標。原倒數前可改選，結束後不能更改。守護只擋狼刀，不擋毒與反傷。

### 狼隊

每位存活狼人選合法目標或放棄，私人面板同步隊友的未選、放棄與目標，原期限前可改票。經典配置不能襲擊狼隊；新增固定配置允許自刀或襲擊狼隊，但惡靈騎士不可被狼刀選中。

全體存活狼人選同一非空目標，伺服器開始私人 3 秒等待，公開倒數不變。改票打破一致取消提前切換，再次一致重新等待；重送相同選擇不延長，全體放棄不觸發。時間到時最高票者遭襲擊，平手在最高票目標中等機率隨機；全體未選或放棄則無襲擊。隨機結果持久保存，重啟不重抽。

### 預言家

每晚查一位其他存活乘客或放棄，提交後不可改。只得知是否狼人，不得知具體角色，所有特殊狼都判狼人。查驗紀錄保留在私人面板。

### 女巫

解藥、毒藥各一瓶，每晚最多用一瓶或放棄，提交後不可改。持有解藥才看得到本晚刀口，使用後不再收到新刀口情報。只有首夜可自救，不能自毒。解藥只擋狼刀，不擋毒或反傷；守護不擋毒。

選「同守同救死亡」時，被狼刀且同時被守護及解救者仍死亡；選「存活」時可擋刀。女巫不知道守衛選擇。逾時未送出視為放棄，已耗藥不返還。

### 惡靈騎士

狼隊成員，不能自爆或成為狼刀目標，永久免疫夜間傷害。女巫毒藥對其無效但仍消耗。全局一次反傷：首次被查驗或下毒，施術者天亮死亡；固定夜序是查驗先於下毒，所以同驗同毒只反傷預言家。守護它不反傷，解藥或守護不能救回反傷者。

白天可被放逐、白狼王帶走或開槍擊殺。夜晚結果公布後的開槍視為白天技能，因此晨間獵人也能射殺惡靈騎士。

## 死亡與連鎖技能

最後夜間時段結束，同時結算狼刀、守護、解藥、毒與反傷，公布遇害者；無人死亡為平安夜。暗牌不公開一般死者角色，明牌在出局時公開；兩者都不公開秘密用藥或具體夜間死因。

新配置先確認死亡，依序處理死亡技能及衍生死亡，再處理警徽，最後判勝負。同一人技能只處理一次，重送或重連不會重複開槍。

- **獵人**：被狼刀、放逐、開槍或白狼王帶走可開槍，30 秒內選存活目標或放棄，一般配置逾時放棄。若死因同時涉及毒藥則不能開槍，即使也遭狼刀。
- **獵殺潛狼**：強制開槍，不能主動放棄；逾時伺服器隨機選合法目標，無目標才略過，支援四獵人連鎖。
- **狼王（黑狼王）**：被狼刀、放逐、開槍或白狼王帶走可開槍；毒殺、自爆不能開槍，可與獵人連環帶人。
- **白狼王**：白天發言時可主動自爆並帶一位其他存活玩家；投票、結果確認不可發動。被放逐、毒殺或槍殺不發動。先處理衍生獵人／狼王技能及警徽，未結束才進下一晚。
- **普通狼人及狼王自爆**：新配置白天發言時可自爆，公開角色並出局，不能帶人或觸發狼王開槍。經典模式不提供。
- **白癡**：首次被放逐自動翻牌留場，公開角色、仍能發言，永久失去票權且不能競選警長。持有警徽時交給有票權的存活玩家或撕毀。再被放逐、夜刀、中毒或技能擊殺均會死亡。

死者不能再用夜間技能、發言、投票或參加結果準備；只有已觸發死亡技能與交徽可操作。死亡不授予上帝視角。結果保留到全體存活玩家確認，顯示尚未確認者。

## 發言與放逐

沒有警長時按席位發言，每天起點往後輪替並略過死者；有警長時選起點及順／逆時針，逾時用預設順序。畫面顯示發言者與倒數，只有本人可提前結束，房主或觀戰者不能代按。

全員發言完進密票：有票權存活玩家可投存活玩家（包含自己）或棄權，提交不可改；翻牌白癡不能投但仍可被投。全員合法投票人送出或到期才公開，未投視為棄權。普通票一票，警長一票半。唯一最高票放逐或觸發白癡首次翻牌。

首輪同票，確認後只對同票目標加投一次，不加發言，所有仍有票權者可投。再次同票或全部棄權則無人放逐，確認後進下一晚。

## 警長

可啟用配置在首天天亮確認後選舉。警長是公開額外職務，不改角色陣營，狼人可競選。報名倒數內可加入／退出；無人無警長、一人直接當選。多人依席位競選發言，開始發言後可退選但不能加入。

非候選且有票權的存活玩家密票選舉，無合法投票人則無警長。同票者再發言加投一次，第二輪僅仍參選者不能投，再平票或全棄權則無警長。警長決定每日發言順序並有一票半放逐票。

警長死亡或白癡警長翻牌失去票權，有 30 秒交徽給有票權的存活玩家或撕毀；逾時撕毀。只有原持有人能操作，撕毀後不重選。

## 勝敗與回房

所有連鎖技能及必要交徽處理完才判勝負：

| 規則 | 好人獲勝 | 狼人獲勝 |
| --- | --- | --- |
| 屠城 | 所有狼人出局 | 所有好人出局 |
| 屠邊 | 所有狼人出局 | 所有村民或所有神職出局 |
| 經典人數優勢 | 所有狼人出局 | 存活狼人不少於存活好人 |

無村民或無神職配置不可採一般屠邊。第三版新局（含經典配置）在連鎖後雙方全滅時判平局並另計統計；經典仍保留人數優勢勝利條件，第一、二版舊局保留當時判定。中止局、測試房不計勝敗。

結束公開所有角色，桌面保留 8 秒後回原等待室，邀請、成員、房主、歷史保留，可換遊戲或再開局。房主可中止；全員離線依框架 60 秒租約結束，不因單人斷線立即終止。

## 觀戰、復盤與相容性

盲視角只讀公開階段、死亡、已翻牌角色、發言者、警長、已揭曉票及結果。上帝視角按框架授權看當下私人資料，不能操作。內部死亡佇列、未公開死因、隨機順位與私人提前期限不直接下發。

每局保存配置快照與規則版本。舊對局、回放保留當時配置、勝負與技能行為：第一版四段夜序，第二版按經典配置略過未登場職業，第三版按本局固定配置。所有版本都只允許狼人一致選人提前結束，神職等待完整公開倒數。

復盤分享不重啟倒數、不補播音效；分享有期限、固定視角及撤銷權限。PNG 只用公開資料，不將上帝視角秘密印入戰報。虛擬玩家使用同樣合法技能與自己的授權情報。

伺服器決定時間、動作與隨機結果；重連沿用期限，重啟每次最多補進一段，下一段給完整時間。各房狀態、計時、技能及票數獨立。實際網域、憑證、玩家資料、備份與 QA 產物留在 Git 外。
