# 廣告與隱私權

功能程式與隱私權頁面可公開；實際房間暗語、AdSense 帳戶與廣告單元設定只放私有 `.env` 或服務的環境設定，不加入 Git。`.env.example` 只列空白欄位，公開掃描另拒絕非測試用的完整 publisher ID。

## 房間資格

- 不填暗語：直接建立一般房，載入手動廣告。
- `ROOM_CODE`：免廣告房，仍為正式房間並保留正常成績。
- `TEST_ROOM_CODE`：測試房，不載入廣告，依既有規則排除正式統計。

開房不需要密碼。兩個選填暗語留空即停用；設定時至少 16 字元且不能重複。填錯暗語會顯示錯誤，可清空後建立一般房，不會默默改成有廣告房。加入成員沿用邀請與獨立憑證，不需要各自輸入暗語。廣告資格在伺服器建房時保存，不接受前端布林開關；換遊戲、回等待室、換房主與重啟皆沿用。舊的一般房依一般資格處理，舊測試房仍免廣告。

## 私人設定

完整設定 `ADSENSE_CLIENT` 與 `ADSENSE_SLOT` 才啟用，沒有完整設定時不載入 SDK。使用 [AdSense 展示型廣告單元](https://support.google.com/adsense/answer/9274025?hl=en)的手動版位；若要使用完成對局後的穿插廣告，在 AdSense 開啟自動廣告，但只保留「穿插廣告」。關閉錨定、側欄、頁內橫幅、多重、廣告意圖及最佳化現有廣告等會新增或更動版位的選項；並關閉「允許穿插廣告的額外觸發條件」，避免切換分頁或閒置後在遊戲中觸發。另依帳戶與服務地區設定適用的使用者同意訊息。

首頁不載入廣告。房間在授權資訊確認後決定資格，不能以瀏覽器暫存的資格直接載入。從房間開啟的規則及隱私權連結帶不含憑證的房間識別；新頁面以該瀏覽器的身分重新驗證後才載入。無房間身分、失效身分及公開分享回放不載入廣告。

SDK 每份文件僅載入一次；導覽離開已載入 SDK 的頁面會建立新文件，避免一般房留下的程式繼續存在於免廣告房或首頁。廣告載入失敗、被封鎖或逾時不影響遊戲；不依遊戲操作或計時器自動刷新廣告。

桌機與手機皆將手動版位置於頁面內容下方，保留至少 150px 間距，不改 body 寬度、頁面縮放或遊戲欄位比例，也不以浮動廣告遮住牌面與按鈕。穿插廣告由 Google 提供全螢幕與關閉控制，網站不自行包覆展示型廣告或隱藏已投放的廣告。參考 [Google 的自動廣告設定](https://support.google.com/adsense/answer/9305577?hl=en)及[遊戲頁面廣告建議](https://support.google.com/adsense/answer/2768340?hl=en)。實際廣告是否填入、出現時間及審核狀態由 AdSense 決定。

## 完成對局返回等待室

一般廣告房在已觀察的對局完成並被伺服器封存、返回原等待室時，顯示「本局已結束」與「返回等待室」連結。點擊後以同分頁的普通連結重新載入該房間；網址只帶公開房號與已完成的對局識別，不含憑證、邀請、暗語或牌局秘密。不自行觸發 SDK 私有函式、不刷新展示型版位、不等待廣告回呼，也不在伺服器延遲回房。廣告被阻擋、未填入或因頻率限制而未顯示時，連結照常導覽。房間成員與遊戲設定均保留。

所有登錄遊戲的玩家與觀戰沿用同一個入口。免廣告房、測試房、首頁、公開分享與復盤不產生此入口；房主中止、空房中止、換遊戲、單純重新連線及直接開啟等待室也不觸發。既有其他站內連結加上 `data-google-vignette="false"`，只有完成對局的返回連結保留 Google 判定機會；額外觸發條件仍須在帳戶關閉。這不是 H5 Games Ads，不需要其資格，也不保證每一局必定顯示廣告。參考[穿插廣告](https://support.google.com/adsense/answer/16531962?hl=en)、[排除連結](https://support.google.com/adsense/answer/17016693)與[頻率設定](https://support.google.com/adsense/answer/13956167?hl=en)。

## 隱私權頁

`/privacy`、`/privacy/` 及 `/privacy.html` 提供不需 JavaScript 即可閱讀的政策。內容涵蓋房間與回放、暱稱、題目回饋、必要瀏覽器儲存、廣告 Cookie、資料保存與聯絡方式。`PRIVACY_CONTACT` 設為公開電子郵件或 HTTPS 聯絡頁；服務啟動時以 HTML 跳脫後插入，不從請求參數產生內容。

只有通用 SDK 網址與政策來源列入狹義公開掃描例外；實際帳戶資訊不寫入原始碼、規則、戰報或對局存檔。

## 舊設定升級

請將私有環境設定的 `CREATE_ROOM_KEY` 改名為 `ROOM_CODE`，`TEST_ROOM_KEY` 改名為 `TEST_ROOM_CODE`，移除 `ADFREE_ROOM_KEY`；AdSense 與聯絡欄位維持原值。先更新程式，再整理環境設定並重啟。新變數優先，明確設空會停用該暗語；為讓尚未整理設定的部署仍能更新，缺少新變數時暫時讀取舊欄位。舊 `CREATE_ROOM_KEY` 現在對應免廣告暗語，沒有暗語仍能開一般房。新建房 API 使用 `roomCode`；舊分頁的 `createKey` 僅為相容別名，不恢復強制開房密碼。既有房間仍依建立時保存的廣告資格處理。
