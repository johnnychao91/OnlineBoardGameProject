# 廣告與隱私權

功能程式與隱私權頁面可公開；實際建房密碼、AdSense 帳戶與廣告單元設定只放私有 `.env` 或服務的環境設定，不加入 Git。`.env.example` 只列空白欄位，公開掃描另拒絕非測試用的完整 publisher ID。

## 房間資格

- `CREATE_ROOM_KEY`：一般房，載入手動廣告。
- `ADFREE_ROOM_KEY`：免廣告房，仍為正式房間並保留正常成績。
- `TEST_ROOM_KEY`：測試房，不載入廣告，依既有規則排除正式統計。

兩個選填密碼留空即停用；三者不能重複。密碼只限制建房，加入成員沿用邀請與獨立憑證，不需要各自輸入建房密碼。廣告資格在伺服器建房時保存，不接受前端布林開關；換遊戲、回等待室、換房主與重啟皆沿用。舊的一般房依一般資格處理，舊測試房仍免廣告。

## 私人設定

完整設定 `ADSENSE_CLIENT` 與 `ADSENSE_SLOT` 才啟用，沒有完整設定時不載入 SDK。使用 [AdSense 展示型廣告單元](https://support.google.com/adsense/answer/9274025?hl=en)的手動版位；關閉帳戶對本網站的自動廣告，避免自動版位覆蓋遊戲操作區。另依帳戶與服務地區設定適用的使用者同意訊息。

首頁不載入廣告。房間在授權資訊確認後決定資格，不能以瀏覽器暫存的資格直接載入。從房間開啟的規則及隱私權連結帶不含憑證的房間識別；新頁面以該瀏覽器的身分重新驗證後才載入。無房間身分、失效身分及公開分享回放不載入廣告。

SDK 每份文件僅載入一次；導覽離開已載入 SDK 的頁面會建立新文件，避免一般房留下的程式繼續存在於免廣告房或首頁。廣告載入失敗、被封鎖或逾時不影響遊戲；不依遊戲操作或計時器自動刷新廣告。

桌機寬度足夠時在右側獨立區域呈現，距遊戲至少 150px；較窄螢幕置於內容下方並保留間距，避免遮住牌面與按鈕。參考 [Google 的遊戲頁面廣告建議](https://support.google.com/adsense/answer/2768340?hl=en)。實際廣告是否填入、出現時間及審核狀態由 AdSense 決定。

## 隱私權頁

`/privacy`、`/privacy/` 及 `/privacy.html` 提供不需 JavaScript 即可閱讀的政策。內容涵蓋房間與回放、暱稱、題目回饋、必要瀏覽器儲存、廣告 Cookie、資料保存與聯絡方式。`PRIVACY_CONTACT` 設為公開電子郵件或 HTTPS 聯絡頁；服務啟動時以 HTML 跳脫後插入，不從請求參數產生內容。

只有通用 SDK 網址與政策來源列入狹義公開掃描例外；實際帳戶資訊不寫入原始碼、規則、戰報或對局存檔。
