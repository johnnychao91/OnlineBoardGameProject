# 圖靈測試

## 故事與定位

機器混入人群的消息，使城市啟動了人性檢測。玩家協助一套不懂分寸與幽默的系統學會解讀人類回答。所有玩家同隊；機器人只是故事背景，不會抽到敵對身分，也沒有指認或放逐階段。

適合 2～9 人，先加入語音通話，用口頭回答表現秘密強度。網站負責抽題、秘密數字、確認、排序與成績，不需要局內打字，不存取麥克風，也不錄音或產生逐字稿。正常題庫名為「人性校準」，無審查題庫名為「失控協定」，各有 1,000 道原創題目。混合模式使用兩套共 2,000 題；自訂模式可只使用房主的題目。

## 本平台流程

1. 房主選標準五關或無盡挑戰。2～3 人沒有檢測員，全員一起排序；4～9 人首位檢測員隨機、之後依席位輪換，檢測員不抽牌、不作答。
2. 2～3 人每人各抽一張 1～10 強度牌；4～9 人除檢測員外各抽一張。全桌數字不重複、只有持有人看得到自己的數字。所有人閱讀同一道題目與量表兩端，直接開始交流及排牌。
3. 用語音呈現對應強度，不需開場確認或作答完成按鈕；可以邊交流邊排序，揭牌前自行確認大家都已表達清楚。網站不保存回答內容。
4. 2～3 人在共用桌上自由調整任何人的牌，從左到右排列，達成房規設定的同意條件後一起揭曉，預設所有人同意。4 人以上由檢測員從認為最低的強度開始逐張揭牌。
5. 每張只和緊接著的前一張比較，下降扣一點生命，第一張不扣。9 → 2 → 3 只扣一次。生命歸零則失敗：共排桌仍一次公開完整排列以便復盤；檢測員玩法停止後續揭牌。
6. 本關全部揭完且仍有生命，停留在最後結果，達成「檢查完畢下一題」設定的同意條件才換關。標準模式通過第五關即成功；無盡模式繼續挑戰。終局保留至少八秒後返回原等待室。

量表只代表回答程度，不是對玩家個性的評分。情境可以虛構，不需分享真實私事；不可直接公布數字或設計暗號。排序時可重述原回答，但不要用新提示改變答案。系統驗證合法操作，不會判斷口頭回答是否完成、幽默程度或作弊。

## 2～3 人共用排序桌

| 人數 | 檢測員 | 受測者 | 本關排序張數 |
| --- | --- | --- | --- |
| 2 人 | 無，全員排序 | 每人各一張 | 2 張 |
| 3 人 | 無，全員排序 | 每人各一張 | 3 張 |
| 4～9 人 | 1 人 | 其餘每人一張 | 人數減一 |

中央使用橫向桌面，所有卡牌直接列在桌上，不設待排區或大型格框。排序前後與揭牌後的卡片保持固定尺寸及圖像比例。任何玩家都能拖曳任何人的牌插入新位置，也能先選一張再點另一張，將選取的牌移到該位置；鍵盤左右鍵可搬動目前焦點卡牌。桌面即時同步，自己能看自己的牌，其他人的數字仍隱藏。

所有卡牌一開始就在桌上，可以直接同意原本的順序，不必逐張放入。任何改動都會清除先前同意；不變的排列不會無故清除。所有人同意模式中，尚未全票時可撤回自己的同意。達成設定條件後，伺服器依該版排列一次揭曉、結算並鎖定，不能再改牌。每次下降扣一點生命，最低為零；失敗關不計入通關數。下一關重新抽題、發牌，所有人繼續共同排序。

共排桌在姓名旁顯示目前階段的準備狀態：所有人同意模式逐人顯示是否同意排列，房主模式只標記房主；任何人模式不要求逐人準備。結果停留時改依「檢查完畢下一題」的同意方式顯示。同意、撤回同意與下一輪確認共用右側操作區，中央不再另列揭曉順序與未確認名單。

切換視窗或分頁會保留秘密資訊的開合狀態；只有手動收起時，才會遮住私人資訊及自己桌面牌上的數字。觀戰與復盤沿用相同桌面，能看公開排列與準備狀態，但不能搬牌；上帝視角依已授權資訊顯示秘密數字。即時觀戰房主可以管理同意設定與結算無盡挑戰，但不能代替參與者確認，復盤始終唯讀。

## 同意方式

房主可分別設定「重抽題目」、「確認排序」與「檢查完畢下一題」，三者預設都是「所有人同意」。這三個選單改選後立即儲存，畫面顯示伺服器確認結果，不需再按下方套用；等待室改選會清除準備；遊戲中從左上方「房間管理」展開「同意方式」即可即時調整。遊戲中變更保留題目、牌面、關數與生命，清除尚未完成的排序、重抽及下一題同意，避免把舊票算到新規則。既有存檔缺少設定時仍採所有人同意。

| 同意方式 | 生效條件 |
| --- | --- |
| 房主同意 | 由參與名單中的目前房主按確認立即執行，不需其他人先行同意；觀戰房主不能選擇或批准此模式。 |
| 所有人同意 | 每位參與玩家都同意後執行，觀戰者不計入人數；排序及重抽尚未全票前可以撤回。 |
| 任何人同意 | 任一參與玩家按確認便立即執行；一般觀戰者不具操作權。 |

「確認排序」僅影響 2～3 人共排桌；4～9 人仍由檢測員逐張揭牌。「重抽題目」及「檢查完畢下一題」適用全部人數。房主轉觀戰或房內沒有有效參與房主時，原本的房主同意會改為所有人同意；載入舊設定時同樣處理。房主離開但有其他參與玩家接任時，權限跟隨正式交接，不綁定原本席位。觀戰房主仍可選擇所有人／任何人模式。

## 題目評分與重抽

參與當局的玩家可在原本題目評分位置，分別替「題目主題」、「1 的敘述」、「10 的敘述」按讚、倒讚、改票或撤回。遊戲牌仍是 1～10，低端點以 1 標示。同一局、同一席位、同一份題目內容的每個面向各保存一票，三者獨立且重複送出不累加。正式內建題按題目內容版本彙整，自訂題及測試房評分隔離保存。舊整題評分保留為舊總評，不擅自分配到三個面向；本次全面改寫後的新題文重新累積評分。資料放在私有資料目錄，可跨重啟保留；不保存暱稱或玩家憑證，不進 Git，不改變生命、勝敗或挑戰成績。觀戰者、舊題頁面及公開復盤不能提交評分。

新局在尚未揭開任何牌時，可依房規設定的同意方式換題。達成條件後抽不同的題目，保留每人的秘密數字、關數、生命與檢測員，將全牌重設為初始順序，清空排序同意及重抽票。所有人同意模式可撤回自己的票；重抽提案期間仍可搬牌，但不能揭牌或同意排序。搬牌不取消同意換題，撤回重抽則使先前延遲的操作失效。沒有其他可抽題目時不能發起重抽。重抽的新舊題文都留在復盤中，未來題序仍隱藏。

## 標準與無盡模式

標準模式固定五關，起始生命為玩家人數，最低 3、最高 8。通過五關仍有生命則成功；生命耗盡則失敗。

無盡模式沒有關數上限，起始生命預設 5，房主可在等待室選擇 1～20。每次排序下降扣 1，通關不補血。生命耗盡時記錄「完整通過關數」：若第 7 關耗盡生命，成績為通過 6 關，失敗關不算通過，即使共排桌已一起揭曉全部卡片也一樣。

房主也可在無盡挑戰途中按「以目前成績結束」，以已完整通過的關數正常結算，當前尚未通過的關不加分。正在看本關結果時，本關已經計入通過數；開始下一關後立即結算也不重複計算。參與或觀戰房主都可使用，其他玩家及一般觀戰者不可。此操作保存正式歷史、復盤及挑戰統計；原有「提前終止遊戲」仍是中止，不計成績。

題池抽完後重新循環，相鄰兩關不會同題。只用五道自訂題也可持續挑戰。房間歷史、復盤與 PNG 都會呈現模式、關數、生命與揭牌結果；全站挑戰統計依玩法、人數、起始生命分組，顯示最佳及平均通過關數。共排桌與舊版檢測員玩法分組，也不混入標準模式勝敗。測試房與未結算的提前中止不列入成績，不以暱稱建立個人排行榜。

## 題庫格式與品質

`src/games/turing/questions/` 保存四份靜態 JSON，每份 500 題。每道題有獨立穩定 ID、類別、題幹、低端點、高端點；不是執行時排列名詞產生的組合題，也不需外部模型或金鑰。正式對局把抽中題文保存到對局，未來修改題庫不會改變舊復盤。

量表兩端描述同一個面向的鮮明極端。「1」不是普通或稍微，而是和「10」明確相反、有情境畫面的那一端；例如室友題是「聽完想立刻逃走報警」到「聽完想立刻簽約同住」。1 不固定代表負面：若 10 是極度驚慌，1 就是極度安心。題幹保留足夠的作答空間，避免先限定一定要稱讚或開心，卻又要求玩家表現失望。

所有題目以短句、名稱、回覆或虛構描述作答；題目中的「寫下」「留言」均直接口述內容，不需真的打字。內建題不要求身體表演、攝影上傳、真實自白或執行危險活動。失控協定以成年人的曖昧、尷尬、社交虛偽與黑色幽默為主，不含露骨性描寫。房主在等待室選擇，切換設定會清除準備。

自訂題目每房最多 50 題，題幹 5～200 字、兩端各 1～50 字；兩端不可相同，題幹不得重複。只玩自訂至少五題，與內建混合則沒有最低數量。輸入先在本機編輯，按套用後才寫入房間；可下載及匯入 JSON 陣列：

```json
[
  {
    "prompt": "替第一次放假的機器人寫下今天的行程。",
    "low": "忙到比上班還想逃",
    "high": "快樂到想永遠放假"
  }
]
```

自訂與內建題幹相同時，採用自訂版本及其量表端點，不重複抽取同一題幹。房間自訂內容與歷史只放在私有資料目錄，不進入 Git，也不自動公布到全站。自訂題庫對房間成員可見；伺服器抽題記錄不對玩家、盲觀戰、上帝觀戰或回放公開。

## 框架接入

- 沿用房間、邀請、觀戰席、房主權限、結束回房、全員離開中止、統計、持久化與跨房隔離。
- 每關發牌與抽題由伺服器裁定；每項互動帶版本，防止重複與舊分頁誤操作。新局不保存口述完成狀態；共排桌允許參與者搬動任何人的牌，達成同意條件後由伺服器原子結算。房主專用操作在房間佇列內重新驗證目前房主權限，不能靠瀏覽器傳入身分旗標繞過。4 人以上只有當關檢測員能揭牌。未揭強度不進入公開協定紀錄。
- 共排桌每次變更排列都更新版本並清除同意；撤回同意也更新版本，讓先前延遲送達的同意失效，其他人的既有同意則保留。並行操作採伺服器接受的次序，過期的搬牌與同意不能覆蓋更新後的桌面。持久化保存排列及尚未達成全票的同意，重連或重啟後不會自行揭牌。
- 實戰、觀戰與復盤共用版面：桌機歷史在左、回答桌面在中央、秘密資料在右；手機自然捲動。秘密資訊由玩家手動開合，切換分頁不變更開合狀態。
- 盲視角只顯示已公開內容；上帝視角可看當下強度。觀戰者需另外加入外部通話，網站不轉送語音。所有視角都無法預知題目抽選順序。
- PNG 戰報明確挑選公開欄位，不讀取私密物件；復盤分享沿用框架的視角、期限與撤銷機制。新局復盤只重現題目與操作，無法重播外部語音。
- 提供提示音、音量、精簡／美術風格、詳細規則與檢測設備圖鑑。測試房虛擬玩家模擬確認並隨機排序，不會在語音中發聲，所有測試局排除於統計。

## 舊版對局相容

更新前已開始的 `rulesVersion: 1` 文字局沿用原先封存回答規則，`rulesVersion: 2` 語音局保留原先少人雙卡與檢測員流程，`rulesVersion: 3` 共排桌保留原先開場及口述確認。新局使用 `rulesVersion: 4`：2～3 人共同排序，4～9 人沿用輪值檢測員；所有新局直接開始排序，支援依房規同意方式重抽。既有存檔未指定同意方式時視為所有人同意，復盤依保存版本顯示當時的回答、題文與揭牌結果。

舊共排桌若只保存部分排列，顯示時保留原有順序，再補齊其餘卡牌；讀取本身不改寫存檔。之後調整或同意便保存完整排列。舊客戶端的移出操作會改為移到最末位，不會再讓卡牌離開桌面。
