# 圖靈測試

## 故事與定位

機器混入人群的消息，使城市啟動了人性檢測。玩家協助一套不懂分寸與幽默的系統學會解讀人類回答。所有玩家同隊；機器人只是故事背景，不會抽到敵對身分，也沒有指認或放逐階段。

適合 4～9 人，完全使用文字完成，不需要攝影機、語音或現場動作。正常題庫名為「人性校準」，成人向題庫名為「失控協定」，各有 1,000 道原創題目。混合模式使用兩套共 2,000 題；自訂模式可只使用房主的題目。

## 本平台流程

1. 一局五輪，初始容錯等於玩家人數，九人局使用八點。首位檢測員隨機，之後依席位輪換；檢測員不抽數字、不作答。
2. 其餘受測者各抽一個不重複的 1～10，只有自己能看見。閱讀題目與量表兩端後全員確認。
3. 用最多 160 字的文字呈現自己的強度，送出後不能修改。全部回答提交前，其他人只能看到完成狀態；全員提交後一次公開。
4. 檢測員依回答內容，從認為最低的強度開始逐張揭數字。每張只和緊接著的前一張比較，下降便扣一點容錯；新的數字成為下一次基準。
5. 第一張不扣分；9 → 2 → 3 只在 2 被揭曉時扣一次。容錯歸零立即失敗，不等待整輪結束。
6. 本輪全部揭完，停留在最後結果，直到全員確認才換輪。完成第五輪且仍有容錯，全隊成功。終局保留至少八秒後返回原等待室。

量表只代表回答程度，不是對玩家個性的評分。情境可以虛構，不需分享真實私事；不可直接公布數字或設計暗號。系統驗證合法操作及長度，不會宣稱能自動判斷幽默、作弊或語意強度。

## 題庫格式與品質

`src/games/turing/questions/` 保存四份靜態 JSON，每份 500 題。每道題有獨立穩定 ID、類別、題幹、低端點、高端點；不是執行時排列名詞產生的組合題，也不需外部模型或金鑰。正式對局把抽中題文保存到對局，未來修改題庫不會改變舊復盤。

所有題目以短句、名稱、回覆或虛構文字描述作答。內建題不要求身體表演、攝影上傳、真實自白或執行危險活動。失控協定以成年人的曖昧、尷尬、社交虛偽與黑色幽默為主，不含露骨性描寫。房主在等待室選擇，切換設定會清除準備。

自訂題目每房最多 50 題，題幹 5～200 字、兩端各 1～50 字；兩端不可相同，題幹不得重複。只玩自訂至少五題，與內建混合則沒有最低數量。輸入先在本機編輯，按套用後才寫入房間；可下載及匯入 JSON 陣列：

```json
[
  {
    "prompt": "替第一次放假的機器人寫下今天的行程。",
    "low": "最像還在上班",
    "high": "最懂得享受假期"
  }
]
```

自訂與內建題幹相同時，採用自訂版本及其量表端點，不重複抽取同一題幹。房間自訂內容、玩家回答與歷史只放在私有資料目錄，不進入 Git，也不自動公布到全站。自訂題庫對房間成員可見；抽選後的未來題目順序不對玩家、盲觀戰、上帝觀戰或回放公開。

## 框架接入

- 沿用房間、邀請、觀戰席、房主權限、結束回房、全員離開中止、統計、持久化與跨房隔離。
- 每輪發牌與抽題由伺服器裁定；每項互動帶版本，防止重複與舊分頁誤操作。未公開回答與強度不進入公開協定紀錄。
- 實戰、觀戰與復盤共用版面：桌機歷史在左、回答桌面在中央、秘密資料在右；手機自然捲動。收起或離開分頁時遮住秘密資訊與未送出的回答。
- 盲視角只顯示已公開內容；上帝視角可看當下強度及已封存答案。所有視角都無法預知題目抽選順序。
- PNG 戰報明確挑選公開欄位，不讀取私密物件；復盤分享沿用框架的視角、期限與撤銷機制。
- 提供提示音、音量、精簡／美術風格、詳細規則與檢測設備圖鑑。測試房虛擬玩家使用合法動作，所有測試局排除於統計。
