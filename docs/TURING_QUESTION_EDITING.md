# 圖靈測試題目編寫

內建題庫維持「人性校準」與「失控協定」各 1,000 題。題目可以直接口頭回答，不要求開鏡頭、演出、繪圖或揭露玩家私事。

## 每題檢查

1. 以熟悉情境為主，最多加入一個容易理解的奇特變化。
2. 讓玩家創造具體事件、台詞、物品或安排，避免只問抽象感受。
3. 題幹與兩端使用同一比較方向。不要把說服力、長度、複雜程度混成一條量表。
4. 端點描述回答造成的效果，不直接填入可照念的答案。
5. 低端與高端都要清楚鮮明，任何數字都能用簡短口述呈現；高數字不代表要說更多話。
6. 控制廣告、致詞、感言等形式的重複密度；評估具體題面，不因分類名稱一概保留或刪除。

題庫改版須逐題檢查全部題幹與兩端，不能只替換幾個形容詞或統一加上前後綴。自動檢查僅負責總數、唯一性、格式與長度，不能取代內容審查。

## 身分與回饋

- 保留題目的 ID；如果整個情境被淘汰，退役原 ID 並分配新 ID，不把新情境塞回舊編號。
- 題目快照包含 ID、分類、題幹及兩端。已抽出的題目和復盤保存當時文字；下一次抽題才使用新版題庫。
- 題目主題、1 的敘述、10 的敘述各有獨立讚／倒讚。同一局、席位、題目快照、評分項目不重複計票，可以切換或撤回。
- 舊版整題評分保留為原有總評，不重新歸類為主題或端點評分。改寫後的題目快照重新累積評分。
- 原始回饋、匯出及逐題稽核紀錄保留在 Git 外，不提交正式玩家資料。
