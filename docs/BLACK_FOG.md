# 黑霧襲城

黑霧切斷了城市與外界的聯繫。守夜騎士必須輪流組隊，前往城郊燈塔重新點亮守護之光；混入隊伍的黑霧使徒則企圖讓行動失敗。兩位蘭斯洛特身上的詛咒，還可能在鐘聲響起時改變效忠對象。

本遊戲供 5～10 位參與玩家遊玩。觀戰者另列名單，不計入人數、不參加表決或準備確認。可以討論、質疑與謊報身分，但不要展示自己的秘密面板來證明，也不要將觀戰所得的秘密轉告玩家。

## 房間與開局設定

房間可以先不選遊戲。房主在等待室選擇「黑霧襲城」，再決定特殊角色與詛咒之鐘模式；參與人數由開局時實際入座的人決定。更換遊戲或規則會清除全員準備，保留成員與邀請連結，讓大家重新確認設定。

梅林與刺客固定登場。派西維爾、莫甘娜、莫德雷德、奧伯倫可由房主勾選；蘭斯洛特成對加入。莫甘娜須搭配派西維爾，任何特殊角色都占用同陣營原有的名額，不額外增加人數。若設定超過實際人數可容納的角色數，開局會被阻止，不會自動移除已選角色。

預設為「隨機詛咒之鐘」，其他可選特殊角色關閉。以 5 人為例，角色是梅林、正義蘭斯洛特、忠臣、刺客、邪惡蘭斯洛特。房主也可選「不使用蘭斯洛特」，改用梅林、刺客及其他已選角色，剩餘名額以忠臣、爪牙補足。

「可互認使徒」包含刺客、莫甘娜、莫德雷德與爪牙。他們知道其他初始黑霧使徒的位置，但不會看見奧伯倫，也不會直接得知同伴的具體角色名稱。他們能看見邪惡蘭斯洛特；邪惡蘭斯洛特看不見他們。

兩種詛咒之鐘模式使用相同的開局情報規則：兩位蘭斯洛特不互認，邪惡蘭斯洛特也不參與使徒互認。這與某些不轉換陣營的蘭斯洛特玩法不同；本遊戲目前提供的是下面兩種轉換模式。

鐘聲不會重新發角色，也不會更新任何人的開局情報。例如原先被梅林看見的邪惡蘭斯洛特，轉為守夜騎士後仍留在梅林的「初始使徒」名單。請將情報理解為開局線索，不能當成即時陣營名單。

巡夜名冊依自己的情報標示陣營。已揭示的鐘聲發生奇數次轉換後，無法辨認哪位初始使徒是蘭斯洛特，相關線索改標「開局黑霧使徒・現效忠未明」；不使用未揭示的預示鐘牌推測。派西維爾看到的兩位梅林候選也不直接標為守夜騎士。收起秘密資訊時，名冊一併隱藏這些標示。

## 每座城郊燈塔的流程

### 1. 詛咒之鐘與隊長提名

如果啟用蘭斯洛特，在每座新燈塔開始組隊之前先處理本座鐘牌。接著由隊長提名表格指定人數的隊伍，可以包含自己，同一個人不能重複入選。

隊長點選人員時，所有人會即時看到目前提名。人數正確並確認後，才開始正式表決。隊長在確認前可以改選，不代表提名者已經出征。

### 2. 全員秘密表決

所有參與玩家各投一次贊成或反對，包含未獲提名的人。投票送出後不能修改；在全員交齊前，其他玩家與盲視角只看到誰已投票，看不到選擇。

贊成票必須嚴格超過參與人數的一半才通過，平票視為否決。全員交齊後公開每人的選擇，所有參與者確認表決結果後才繼續。

- 通過：由提名隊伍執行本座燈塔任務，連續否決次數歸零。
- 否決：隊長依座位順序交給下一位，重新為同一座燈塔組隊。沒有新增任務，也不重抽或重複套用鐘牌。
- 同一座燈塔連續第 5 次組隊被否決：黑霧使徒獲勝。畫面仍先保留第五次表決，待全員確認後呈現終局。

### 3. 秘密執行任務

只有入選隊員提交行動，每人一次。選擇「守護燈塔」或「侵蝕燈塔」，送出後不可撤回或更改。

| 目前效忠及角色 | 可以提交的行動 |
| --- | --- |
| 目前效忠守夜騎士，任何角色 | 只能守護燈塔 |
| 目前效忠黑霧使徒，一般使徒角色 | 守護或侵蝕燈塔皆可 |
| 目前效忠黑霧使徒，隨機模式的任一蘭斯洛特 | 守護或侵蝕燈塔皆可 |
| 目前效忠黑霧使徒，預示模式的任一蘭斯洛特 | 必須侵蝕燈塔 |

伺服器依目前陣營執行限制，不能透過修改網頁、重送舊操作或其他人的座位來提交不合法行動。非隊員只等待結果，不需要提交任務行動。

### 4. 揭曉與全員確認

所有隊員交齊後，只公開守護與侵蝕的合計張數，不公開每張行動的主人。

一般任務只要出現 **1 張侵蝕**，本座燈塔就失守。唯一例外是 **7～10 人局的第 4 座燈塔**：必須至少 **2 張侵蝕** 才失守，只有 1 張仍能成功點亮。這項例外只適用第 4 座，其他座次與 5～6 人局都不適用。

結果畫面會保留本座隊伍、張數與成敗，列出尚未確認的人。全體參與者確認後，才進入下一座燈塔或勝負判定。若仍需繼續，隊長依座位順序交給下一位；下一座需要的人數依表格決定。

觀戰者不參與任何確認。確認按鈕只是表示已看完資訊，不是再次投票，也不會改變已判定的結果。

## 詛咒之鐘：兩種蘭斯洛特模式

兩種模式都把正義與邪惡蘭斯洛特各加入一位。每次「效忠轉換」會讓兩人交換**目前**效忠，因此全場兩方人數比例不變。轉換會影響本座起的任務限制及最後勝敗歸屬；請以自己的「目前效忠」欄位為準，不能只看角色名稱。

### 隨機模式

使用 6 張鐘牌：**4 張保持效忠、2 張效忠轉換**。開局洗勻牌堆，從**第 1 座燈塔起**，在每座新燈塔開始組隊前公開抽出一張。

保持效忠不改變陣營；效忠轉換讓兩位蘭斯洛特交換陣營。已揭鐘牌保留在操作紀錄，未揭牌序始終隱藏。最多進行五座燈塔，因此不一定會抽完整疊牌，也不保證每局發生相同次數的轉換。

此模式目前效忠黑霧使徒的蘭斯洛特可以選擇守護或侵蝕；目前效忠守夜騎士的蘭斯洛特仍只能守護。

### 預示模式

使用 7 張鐘牌：**5 張保持效忠、2 張效忠轉換**。洗勻後取出 5 張，開局依順序公開，分別對應第 1～5 座燈塔；另外 2 張不使用，也不公開。

每座新燈塔開始組隊前，套用已公開的對應鐘牌。玩家可以預先知道哪些座次會發生轉換；同一座組隊遭否決時，不重複套用。

此模式有一項額外限制：**目前效忠黑霧使徒的蘭斯洛特，出征時必須侵蝕燈塔**。目前效忠守夜騎士的蘭斯洛特仍只能守護。這項限制依目前效忠判斷，不依角色上的「正義／邪惡」名稱判斷。

例如第一座發生轉換：正義蘭斯洛特改為黑霧使徒，若入隊就必須侵蝕；邪惡蘭斯洛特改為守夜騎士，只能守護。之後若再發生一次轉換，兩人的效忠與限制再次交換。

本專案採用 Big Box 規則書的兩種轉換版本：隨機模式從第一座開始，使用 6 張鐘牌，不是其他版本中「第三次任務起、使用 5 張牌」的流程。版本資訊可查閱 [出版社的 Avalon Big Box 產品頁](https://indieboardsandcards.com/our-games/avalon-big-box/)；以上角色能力與兩種轉換模式已核對該版規則，說明文字為本專案重新撰寫。

## 最後指認與勝負

三座燈塔失守，黑霧使徒獲勝；同一座連續五次組隊被否決，黑霧使徒也獲勝。這兩種情形都不進行刺客指認，最後一份任務或表決結果先供全員確認。

三座燈塔成功點亮，還不能立即判守夜騎士獲勝。看完第三次成功結果後，進入刺客最後指認：

1. 所有人可以討論，角色仍未全部公開。
2. 只有持有刺客角色的人可以指定一位其他參與玩家，並確認送出。
3. 指認對象是梅林：黑霧使徒逆轉獲勝。
4. 指認對象不是梅林：守夜騎士獲勝。

其他角色不能代替刺客操作。線上介面允許刺客選擇任何其他實際席位，不藉由禁止選取某個人洩露隱藏陣營；選到非梅林就算沒有命中。

終局會公開所有人的角色與目前效忠。蘭斯洛特按結束當下的陣營判定歸屬，角色名稱不會改寫。結果保留約 8 秒後，自動回到原等待室；房間、成員、觀戰席與有效邀請保留，可重新準備再玩。

## 線上權限、連線與多人房間

房主可在等待室設定遊戲、管理邀請及單次移出其他參與玩家；被移出者仍可持有效邀請重新加入。遊戲開始後不能換角色、移出參與者或改規則，房主可以提前中止並讓全房返回等待室。房主改為觀戰仍保有管理權，不占玩家名額，也不需要準備。

所有人都離線超過連線寬限期後，遊戲會自動中止；預設約 60 秒，實際處理時間還會受背景檢查間隔影響。只要還有玩家或觀戰者維持連線，就不算全員離線。房主中止與全員離線中止都不計勝敗，不開放未完成對局的完整秘密回放。

所有合法操作以伺服器收到及處理的狀態為準。多人同時投票、提交行動或確認時，可以各自完成，不必輪流等待其他人的畫面刷新；同一個人的重複提交只接受首次合法結果。舊階段的操作不能套用到新階段。

斷線後先等待重新同步，再依最新畫面操作。網路延遲可能讓提名或進度稍晚出現，不代表可以撤回已收到的表決或行動。若某位參與者無法回來，其他玩家不能代投或替他確認，可由房主提前中止。

不同房間與同房的不同對局使用獨立角色、鐘牌、投票、確認與紀錄。兩組或三組朋友同時開房，不會共用身分、隊長、任務結果或邀請權限。

## 觀戰、回放與分享

觀戰者可切換盲視角與上帝視角，包含進行中的對局。觀戰憑證只能觀看，不能提名、投票、提交任務或確認階段。

- **盲視角**：只看公開提名、表決進度、已公布的逐人表決、匿名任務張數與鐘牌紀錄。終局可看公開角色與最終效忠，但不取得各玩家的私人情報或逐人任務選擇。
- **上帝視角**：可看所有角色、目前效忠、開局情報，以及尚未結算的私人表決與任務選擇。任務結算後只保留匿名張數；未來的隨機鐘牌與亂數資料不提供給任何觀戰視角。

完成後可以逐步復盤，分享盲視角或上帝視角的回放連結，並指定分享的步驟。分享權限鎖定建立時的視角與對局，改網址參數不能把盲視角升級為上帝視角，也不能用分享憑證取得玩家席位。上帝視角的回放仍可能看到先前步驟中的秘密，分享前請確認接受公開這些資訊。

也可生成戰報 PNG 圖片；圖片只取公開事件、暱稱與當時進度，不因目前選擇上帝視角就把私人角色面板或未公開表決一起畫出來。回放以操作步驟為單位，不代表能重現每人真實思考或連線等待的時長。

全站統計按已完成對局計算遊戲及陣營勝敗，並記錄實際參與人數。回放、觀戰、重新連線與重複讀取統計都不會增加完成局數或參與人次。
