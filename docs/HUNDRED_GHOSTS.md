# 百鬼夜宴

4～12 人的面具交換與認領遊戲。每人從六枚妖金開始，輪流看自己的面具、暗換面具，或宣稱某位妖怪的名號領取供奉。玩家永遠只有曾經看過的記憶，不能隨時免費查看目前的身分。

## 配置與開始

採《化裝舞會》2021 新版的 16 種角色、17 張面具，保留兩張小豆洗。房主可選官方 A／B 場景，或自訂面具配置。4～5 人固定六張，未分給玩家的牌留在中央；6～12 人的官方場景各配一張，自訂可多一至兩張中央牌。

開場公開全部位置與面具。全員確認後，前四個個人回合只能暗換：與另一位玩家或中央牌交換，也可以假裝交換。操作者不能偷看兩張牌，其他人無從分辨真換或假換。

自訂必須有閻魔，小豆洗只能零張或兩張，至少三分之一的面具能從金庫帶入妖金，且遵守角色最低人數。官方場景直接使用官方表，不另外套用自訂限制。

## 回合與認領

正常回合選一項：查看自己、暗換，或宣稱本局存在的角色。若自己的面具在上一位玩家回合被翻開，本回合只能查看或暗換。

宣稱後，從左手邊依座次逐人決定是否也認領，等所有相關玩家回應才結算，不設倒數。無人爭議時不翻牌，直接執行宣稱能力；有人爭議才翻開所有認領者，真正持有該面具的人執行能力，冒領者於能力完成後各付一枚到供奉盤。

## 勝負與線上裁定

有人達十三枚即獲勝；有人破產時以當時最富有者獲勝。天邪鬼的十枚勝利必須在其能力發動時檢查，不是持有面具便被動生效。

同一指令的多方付款一併結算：招財貓、煙煙羅、絡新婦收款、雙小豆洗及冒領罰款。若同批多人達十三枚，或破產終局時最多妖金平手，共享勝利。分段能力在每段金幣變更後檢查終局，結束後不再換牌、亮牌或罰款；垢嘗每收取一位便檢查。

絡新婦交換的是實體座次，因此左右鄰居及之後行動順序一起改變；從本回合發起者的新位置輪到下一人。房間帳號、登入權限和私人記憶仍屬原玩家，不隨座次交換。

## 資訊與框架

玩家投影不含目前真實面具、牌庫或其他人的私人記憶。暗換與假換使用相同的公開紀錄和不確定標記。百目鬼的查看只給能力使用者；青行燈的揭示不會出現在對所有玩家公開的紀錄中。

盲視角保存公開曾見的面具；上帝視角可看當前面具與私人記憶，切回盲視角會重新過濾。公開 PNG 僅使用公開資訊。房間、觀戰、復盤、邀請、設定記憶、虛擬玩家及重啟保存沿用共用框架。統計採個人競賽，不把玩家名字或席位當作陣營；測試房不列入成績。
